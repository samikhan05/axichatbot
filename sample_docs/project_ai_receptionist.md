# Project: AI Video Reception Chatbot

Status: In development, Phase 1 (text-based core).

This project builds an AI-powered video receptionist for our office lobby.
It will greet visitors, answer questions about the company, and eventually
support voice conversation in English, Urdu, and Roman Urdu with a lip-synced
avatar.

Phase 1 goal: a working text-based chatbot using an LLM and a retrieval
system (RAG) so it can answer questions using real company data.

Team: 2 backend engineers, 1 frontend/React developer.

Tech stack: FastAPI, LangChain, Qdrant, PostgreSQL, React.
